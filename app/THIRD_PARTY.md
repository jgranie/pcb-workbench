# Dépendances et droits avant publication

Aucune licence du code de ce paquet n'a été attribuée. Une absence de fichier
LICENSE n'accorde pas implicitement une permission générale de réutilisation.
Jean doit choisir une licence et confirmer les droits sur les sources copiées
avant publication. Aucun droit photographique n'a été vérifié dans ce travail.

| Élément | Utilisation | Point à vérifier pour distribuer |
|---|---|---|
| Modules JS du prototype local | `tracker-core`, `auto-scan-core`, `pin-row-core`, `trace-edit-core` | Origine et droit de relicencier le code du projet initial. Les copies ont été adaptées à des dimensions génériques pour les microcoupures. |
| Nouveau code et exemple synthétique | Créés pour ce paquet | Choix de licence et titularité à confirmer par Jean. |
| NumPy 2.2.6 | Installé, non embarqué | Licence BSD et notices des bibliothèques incluses dans la distribution choisie. |
| Pillow 12.0.0 | Installé, non embarqué | Licence HPND et notices de sa distribution. |
| OpenCV headless 4.12.0.88 | Installé, non embarqué | Licence Apache 2.0 du projet et notices des composants de la wheel. |
| GIMP 3 | Programme externe facultatif | GPL et dépendances si quelqu'un décide de le redistribuer ; il n'est pas embarqué ici. |
| Python / Node | Programmes externes | Conserver leurs notices si leurs binaires sont distribués ; aucun binaire embarqué ici. |

Le verrou d'installation référence les distributions et leurs empreintes. Il
n'incorpore pas leurs binaires. Les notices effectives restent fournies par
chaque distribution installée. Cette liste est un inventaire de points à résoudre,
pas un audit juridique.

L'archive locale inclut uniquement l'exemple synthétique généré par
`examples/generate.py`. Aucune photo Minitel, boîte WeVisOne, correction utilisateur,
capture privée, XCF ou poids de modèle n'est prévu dans la liste de fichiers.
