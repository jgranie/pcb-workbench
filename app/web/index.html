Détection soudures

WeVisOne détecte les soudures sur 24 sections avec une marge de contexte de 64 px. Les doublons entre sections sont rapprochés prudemment. Un nouveau calcul remplace les propositions automatiques ; vos corrections restent conservées. Sélection : clic, Cmd/Ctrl-clic pour ajouter. Ajout : cliquer sur la carte. Aucun calcul de pistes n’est lancé.

Détection pistes

Balayage CPU entre les soudures conservées, sur l’alpha d’Original-croppé. Sans préparation, le masque CPU initial est utilisé s’il existe. Les visibilités des calques ne changent pas le calcul. Une relance conserve les corrections ; Annuler restaure le résultat précédent.

Jaune : piste fine ; violet : surface large ; orange pointillé : microcoupure proposée ; bleu : tracé manuel. Ce sont des chemins à vérifier.

Sélection : clic, Cmd/Ctrl-clic pour ajouter ou retirer, double-clic pour la chaîne jusqu’aux soudures. Suppr enlève les tronçons ; Valider / À revoir porte sur le chemin complet. Ligne : clics successifs, Maj à 45°, Alt sans aimant, Échap pour terminer. Glisser le fond déplace la carte.

Les inscriptions, trous, reflets et composants restent ambigus ; le filtre des rangées est une hypothèse. Les coordonnées restent en pixels.
